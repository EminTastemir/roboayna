## 📖 About

RoboAyna is an AI-powered smart mirror designed to provide users with a more natural and efficient way to access information without constantly checking their smartphones.

The system combines Artificial Intelligence, Speech Recognition, Large Language Models and Text-to-Speech technologies to create a seamless daily assistant experience.

---

# ✨ Features

- 🎤 Voice Commands
- 🤖 AI Assistant
- ☁️ Weather Information
- 🕒 Time & Date
- 📝 Smart Reminders
- 🎵 Music Control
- 💬 Natural Conversation
- 🔊 Text-to-Speech
- 📺 MagicMirror Interface
- 🌐 Hybrid Offline / Online Architecture

---

# 🛠 Technologies Used

| Technology | Purpose |
|------------|----------|
| Python | Backend |
| Flask | API Server |
| Ollama | Local LLM Runtime |
| Gemma 2B | Language Model |
| Edge-TTS | Voice Output |
| MagicMirror² | Smart Mirror Interface |
| Raspberry Pi | Hardware |
| Speech-To-Text | Voice Recognition |

---

# ⚙️ How It Works

```text
🎤 Voice Command
        │
        ▼
Speech To Text
        │
        ▼
Intent Analysis
(Python + Flask)
        │
        ▼
Gemma LLM
(Ollama)
        │
        ▼
Generate Response
        │
        ▼
Text To Speech
        │
        ▼
MagicMirror Display
```
